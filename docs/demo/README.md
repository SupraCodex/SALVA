# SALVA demo video

`SALVA_demo_en.mp4` is a browser recording of the working English-language flow on a local PostgreSQL-backed instance:

1. create an account;
2. create the 500 kg tomato demonstration lot;
3. inspect the risk estimate;
4. simulate decisions;
5. change an assumption and rerun;
6. inspect the recommendation and ask a constrained “what if” question;
7. open the assumptions and limits page.

## Verification

- Duration: 33.68 seconds
- Video: H.264, 1280 × 800, 25 fps
- Audio: none; the video is a silent screen recording
- No password, token, `.env` file or terminal appears in the recording
- The flow was executed against the local application and the 9 E2E scenarios passed on the same environment
