# SALVA core — requirements traceability

**Status:** assessment of `feat/spectre-core` before this work's code changes.  
**Authoritative source:** `SALVA_Document_de_Conception.docx`, version 1.0 (5 Oct 2026), read in full (133 rendered pages; paragraphs and tables extracted through the final annex).  
**Scope:** scientific Python package `core/` and its explicit interface with P3/backend. This is not a claim that the complete SALVA submission is finished.

The document calls for a pure, reusable engine: quality/loss features and models, Monte Carlo comparison, economics, constrained allocation, risk-aware recommendations, and optional sensitivity analysis. Network integrations, the database, route discovery, explanation/LLM, UI, field validation, training orchestration and submission artifacts belong to other project layers unless a row says otherwise.
